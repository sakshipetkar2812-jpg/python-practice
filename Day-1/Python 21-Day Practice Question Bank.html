DAY 1: Python Basics, Variables, Data Types, input()

Teach (short, Hinglish)

  • Python ek simple, readable, interpreted language hai (code line by line run hota hai). Use: web, data, automation, AI.
  • print() screen par output dikhata hai: print("Hello")
  • Comment: # ye comment hai. Python ignore karta hai.
  • Variable = data ka naam wala box: age = 20. Type declare nahi karna padta.
  • Naming rules: letter ya _ se start, space nahi, keyword nahi (if, for), case-sensitive (age ≠ Age).
  • Data types: int (10), float (3.5), str ("hi"), bool (True/False).
  • type(x) type batata hai. Conversion: int("5"), str(5), float(3), bool(0).
  • input() hamesha string return karta hai. Number chahiye to int(input()).
  • Common mistakes: "5" + 5 error deta hai; input() ko int samajhna; = aur == mix karna.
  • Interview point: Python dynamically typed hai; sab kuch object hai.

DAY 2: Operators and Precedence

Quick revision (5 Qs from Day 1): items 7, 12, 20, 23, 29.

Teach (short)

  • Arithmetic: + - * / // % **. / always float, // floor division, % remainder, ** power.
  • Comparison: == != > < >= <= → give True/False.
  • Assignment: = += -= *= /= //= %= **=
  • Logical: and or not
  • Membership: in, not in. Identity: is, is not.
  • Bitwise basics: & | ^ ~ << >>
  • Precedence (high → low): () → ** → * / // % → + - → comparison → not → and → or.
