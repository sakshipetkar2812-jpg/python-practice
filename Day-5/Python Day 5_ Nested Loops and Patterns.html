Teach (short, Hinglish)

Nested loop kya hai? Loop ke andar loop. Bahar wala (outer) loop rows sambhalta hai, andar wala (inner) loop columns.

for i in range(3):          # outer: 3 rows
    for j in range(4):      # inner: 4 columns
        print("*", end=" ")
    print()                 # row khatam, nayi line

Kaise kaam karta hai: outer ka 1 round hota hai, tab inner poora chalta hai. Phir outer ka agla round. Yani total chalne ki sankhya = outer x inner.

Pattern banane ka formula

  1. Kitni rows hain? (outer loop)
  2. Har row me kitne columns/stars/numbers? (inner loop ki range)
  3. Row number i ke saath columns ka kya relation hai? (i, n - i, 2*i - 1)
  4. Spaces chahiye? Unke liye alag inner loop.
  5. Har row ke baad print() (nayi line).

Digit problems ka standard logic

n = 472
while n > 0:
    digit = n % 10      # last digit nikalo
    n = n // 10         # last digit hata do

Common mistakes

  • Row ke baad print() bhoolna (sab ek line me aa jaata hai).
  • Inner loop ki range me row number i use na karna.
  • Digit loop me original n badal dena aur baad me use karna (pehle copy rakho: temp = n).
  • print(end=" ") aur print() ka confusion.

Real-world use: tables, grids, matrix, seating layout, calendar print karna.

Section B: Debugging

  1. 🟢 Fix (3 rows ka square chahiye, sab ek line me aa raha hai):
for i in range(3):
    for j in range(3):
        print("*", end=" ")
  1. 🟡 Fix (right triangle chahiye, par square ban raha hai):
for i in range(1, 5):
    for j in range(4):
        print("*", end="")
    print()
  1. 🟡 Fix (digit sum hamesha 0 aa raha hai):
n = 123
s = 0
while n > 0:
    s = n % 10
    n = n // 10
print(s)
  1. 🟠 Fix (number ka reverse chahiye, 321 ki jagah galat aa raha hai):
n = 123
rev = 0
while n > 0:
    rev = rev + n % 10
    n = n // 10
print(rev)

Logic-Building Help (pattern atak jaye to)

  1. Pattern ko rows aur columns me likho. Kitni rows? (outer loop)
  2. Row i me spaces kitne? Stars kitne? Formula likho (jaise n - i, 2*i - 1).
  3. Choti value (n = 3) par manually dry run karo.
  4. Pehle simple version banao (square), phir badlo (triangle).
  5. Edge cases: n = 1, n = 0.

Digit problems me: n % 10 = last digit, n // 10 = last digit hatao, loop while n > 0.
