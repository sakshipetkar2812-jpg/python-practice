Teach (short, Hinglish)

Loop kya hai? Same kaam ko baar-baar karne ke liye. 10 baar print karna ho to 10 line nahi likhte, loop lagate hain.

1. for loop (jab pata ho kitni baar chalana hai ya kisi sequence par chalana hai)

for i in range(5):
    print(i)        # 0 1 2 3 4

2. range()

  • range(5) → 0 se 4
  • range(2, 6) → 2 se 5
  • range(1, 10, 2) → 1, 3, 5, 7, 9 (step 2)
  • range(5, 0, -1) → 5, 4, 3, 2, 1
  • End value include nahi hota.

3. while loop (jab condition True rehne tak chalana ho)

i = 1
while i <= 5:
    print(i)
    i += 1          # update bhoolna mat, warna infinite loop

4. break: loop turant band. 5. continue: is round ko skip karke agle round par. 6. pass: kuch nahi karta, sirf khali jagah bharta hai.

Common mistakes

  • while me counter update na karna (infinite loop).
  • range(1, n) likhna jab n bhi chahiye (sahi: range(1, n + 1)).
  • Loop ke andar print ka indentation galat.
  • Loop ke andar variable ko reset kar dena (jaise total = 0 loop ke andar).

Pattern for sum/count/product

total = 0
for i in range(1, 6):
    total += i
print(total)        # 15

for vs while: for = known count / sequence. while = unknown count / condition based.

Real-world use: bill items add karna, ATM retry attempts, data process karna, menu repeat karna.

Section B: Debugging

  1. 🟢 Fix (1 se 5 print karna hai):
for i in range(1, 5):
    print(i)
  1. 🟡 Fix (infinite loop):
i = 1
while i <= 5:
    print(i)
  1. 🟡 Fix (sum of 1 to n hamesha 0 aa raha hai):
n = 5
for i in range(1, n + 1):
    total = 0
    total += i
print(total)
  1. 🟠 Fix (3 se 1 tak countdown chahiye, kuch print nahi ho raha):
for i in range(3, 0):
    print(i)

Section C: Basic Code Writing

  1. 🟢 1 se 10 tak numbers print karo.
  2. 🟢 10 se 1 tak numbers print karo.
  3. 🟢 1 se 20 tak sirf even numbers print karo (do tareeke se).
  4. 🟢 Number n input lo, uski multiplication table print karo (5 x 1 = 5 format).
  5. 🟢 1 se n tak ka sum nikalo.
  6. 🟡 1 se n tak ke numbers ka product (factorial) nikalo.

Logic-Building Help (jab atak jao)

  1. Loop kitni baar chalega? (Fixed hai to for, condition-based hai to while)
  2. Loop se pehle kaun se variables chahiye? (total = 0, count = 0)
  3. Har round me kya hona chahiye?
  4. Loop kab rukna chahiye?
  5. Edge cases: n = 0, n = 1, negative input.
