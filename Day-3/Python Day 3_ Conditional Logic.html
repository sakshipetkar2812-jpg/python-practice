Teach (short, Hinglish)

Condition kya hai? Program ko decision lena sikhata hai: "agar ye sach hai to ye karo, nahi to wo karo."

Syntax

if condition1:
    # condition1 True ho to
elif condition2:
    # condition2 True ho to
else:
    # koi bhi True na ho to

Important rules

  • Condition ke baad : zaroori hai.
  • Indentation (4 spaces) hi block batata hai. Ye galat hua to IndentationError.
  • elif aur else optional hain. else me condition nahi likhte.
  • Sirf pehli True condition ka block chalta hai, baaki skip.
  • Multiple conditions: and, or, not.
  • Nested if = if ke andar if.
  • Ternary: result = "Even" if n % 2 == 0 else "Odd"
  • Falsy values: 0, 0.0, "", [], None, False. Baaki sab Truthy.

Common mistakes

  • = ki jagah == na likhna.
  • elif ki jagah har baar alag if likhna (sab chal jaate hain).
  • Indentation galat.
  • if x == 1 or 2: (ye hamesha True hota hai). Sahi: if x == 1 or x == 2: ya x in (1, 2).

Real-world use: login check, discount, tax slab, ATM PIN, eligibility.

Interview point: if vs elif vs multiple if; ternary operator; truthy/falsy values.

Section C: Basic Code Writing

  1. 🟢 Number input lo. Positive, negative ya zero print karo.
  2. 🟢 Number input lo. Even ya odd print karo.
  3. 🟢 Age input lo. 18 ya zyada ho to "Eligible to vote", nahi to "Not eligible".
  4. 🟢 Do numbers me se bada print karo.
  5. 🟡 Teen numbers me se sabse bada print karo (equal values ka dhyan rakho).

Section D: Real-Life Logic

  1. 🟡 Leap year: year input lo. Rule: 4 se divisible, lekin 100 se divisible ho to 400 se bhi hona chahiye.
  2. 🟡 Grade calculator: marks 90+ A, 75-89 B, 60-74 C, 40-59 D, 40 se kam Fail. (Marks 0-100 ke bahar ho to "Invalid".)
  3. 🟡 Electricity bill: 100 units tak ₹5/unit, 101-200 ke liye ₹7/unit (sirf extra units par), 200 ke baad ₹10/unit. Total bill nikalo.
  4. 🟡 Salary: basic salary input lo. 20000 se kam ho to bonus 10%, warna 5%. Total salary print karo.
  5. 🟡 Age category: 0-12 Child, 13-19 Teen, 20-59 Adult, 60+ Senior.
  6. 🟠 Triangle check: teen sides input lo. Valid triangle hai ya nahi, aur valid ho to type (Equilateral, Isosceles, Scalene).

Section F: Technical Test Style

  1. 🔴 Login Check: Input: username aur password (alag lines). Agar username admin aur password 1234 ho to Login Successful, agar sirf username sahi ho to Wrong Password, warna User Not Found.
  2. 🔴 Shipping Charge: Input: order amount aur city type (metro ya other). Rules: amount 1000+ ho to free shipping. Warna metro ke liye ₹40, other ke liye ₹70. Output: final shipping charge.
  3. 🔴 Largest of Three (without max()): teen numbers input lo, sabse bada nikalo. Sample: 4 9 7 → 9.

Section G: Challenge

  1. 🟠 Quadratic Roots Type: a, b, c input lo. Discriminant b*b - 4*a*c se batao: "Two real roots", "One real root" ya "No real roots". (a = 0 ho to pehle "Not a quadratic" print karo.)

Logic-Building Help (jab atak jao)

  1. Input kya hai? 2. Output kya hai? 3. Pehle copy par manually solve karo.
  2. Konsi conditions ka order matter karta hai? (jaise grade me upar se neeche ya leap year me 400 pehle)
  3. Edge cases: 0, negative, equal values, boundary (jaise 18, 100, 40).
